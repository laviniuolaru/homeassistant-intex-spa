# Contact

If you are Intex, Tuya, or anyone else with a concern about this project — technical,
legal, or about traffic to your servers — please open an issue, or write to the address
on the maintainer's GitHub profile. A message will get a reply.

This project makes one request to Intex's servers when it is first set up, and after
that only when the spa's local key stops working, at most once every ten minutes. If
that volume is a problem, say so and it will be reduced.

For security issues in the integration itself, please open an issue rather than a public
pull request if the problem would be exploitable before a fix ships.
